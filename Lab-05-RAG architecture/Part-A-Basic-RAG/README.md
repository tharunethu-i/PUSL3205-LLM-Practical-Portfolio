# Part A – Basic RAG Implementation

## Project Overview
This section contains the implementation of a basic Retrieval-Augmented Generation (RAG) University Knowledge Assistant.

## Technologies Used
- Python
- Ollama
- Llama 3.2 (3B)
- Qwen3 Embedding (0.6B)
- LangChain
- ChromaDB
- Streamlit

## Main Features
- PDF document loading and processing
- Text splitting and embedding generation
- Vector-based document retrieval
- Cross-encoder reranking
- Context-based answer generation
- Multiple PDF support
- User PDF upload
- Source references

## Main Files
- `app.py`
- `ingest.py`
- `rag_pipeline.py`
- `rebuild_database.py`
- `requirements.txt`
